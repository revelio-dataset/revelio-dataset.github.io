REVELIO

REVELIO extends ADABase with two commercial video games, Hogwarts Legacy broom flight and Overcooked! 2, alongside the n-back protocol, recorded with the same sensors and annotation scheme.

Together with ADABase: 96 sessions from 83 unique participants across four applications · n-back, driving simulator and two games.

Loading the public sets

A Jupyter notebook walks through the ADABase and REVELIO public sets end to end, from the HDF5 layout to model-ready windows with a subject-wise split. Driving and gaming files share one layout, so the same code reads both.
